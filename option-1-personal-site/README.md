# Option 1: Personal Portfolio Site

A beautiful, responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive design (mobile, tablet, desktop)
- Smooth scrolling navigation
- Hero section with call-to-action
- About section with skills
- Showcase of 3 featured projects
- Contact form
- Social media links
- Animations on scroll

## Getting Started

### Option A: Using Live Server (Recommended)
1. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code
2. Right-click `index.html` and select "Open with Live Server"
3. Your site will open automatically in your browser

### Option B: Open file directly
- Simply open `index.html` in your web browser

## Deploy to GitHub Pages

1. Create a GitHub repository named `<your-username>.github.io`
2. Push these files to the repository
3. Your site will be live at `https://<your-username>.github.io`

## Deploy to Netlify

1. Go to [netlify.com](https://netlify.com)
2. Drag and drop the folder into Netlify
3. Your site will be deployed instantly

## Customization

Edit the following to make it your own:
- `index.html`: Change names, descriptions, and links
- `style.css`: Update colors, fonts, and layouts
- `script.js`: Add more interactive features
- Replace placeholder images with real ones

## Color Scheme
- Primary Blue: `#2563eb`
- Secondary Blue: `#1e40af`
- Text: `#1f2937`
- Background: `#f9fafb`

Feel free to customize these in `style.css`!
