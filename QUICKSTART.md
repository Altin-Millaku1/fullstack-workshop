## 🚨 Troubleshooting

**Q: Page won't load?**
- A: Check the file path is correct
- Make sure you're opening `index.html` (not the folder)

**Q: Styles look weird?**
- A: Hard refresh browser (Ctrl+Shift+R)
- Clear browser cache

**Q: JavaScript not working?**
- A: Open DevTools (F12)
- Check for errors in Console tab
- Make sure all `.js` files are in same folder

**Q: Can't deploy?**
- A: Try Netlify (easiest)
- No configuration needed
- Just drag and drop
